# DAM - Prácticas de Desarrollo de Aplicaciones Multiplataforma
 
## Descripción
 
Este repositorio recoge mi proceso de aprendizaje durante el primer año del ciclo formativo de **Desarrollo de Aplicaciones Multiplataforma (DAM)**.
 
El objetivo principal es practicar, consolidar conocimientos y desarrollar un pensamiento lógico y estructurado orientado a la resolución de problemas mediante la programación.
 
Aquí almacenaré ejercicios realizados en clase, prácticas personales, retos de programación y actividades relacionadas con las asignaturas técnicas del ciclo.
 
---
 
## Objetivos
 
- Aprender los fundamentos de la programación.
- Desarrollar pensamiento lógico y algorítmico.
- Mejorar la capacidad de análisis y resolución de problemas.
- Aplicar buenas prácticas de programación desde el inicio.
- Comprender la importancia de la programación estructurada.
- Crear una base sólida para futuros proyectos y tecnologías.
